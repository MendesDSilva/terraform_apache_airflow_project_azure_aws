# Skills do projeto

Consulte a skill da área antes de alterar código: airflow, aws, azure, databricks,
terraform, pyspark, security, cicd, testing e documentation. Combine, por exemplo,
aws + terraform + security para infraestrutura AWS. O prompt em .codex/skills
registra os requisitos; docs/architecture.md registra a adaptação aprovada à Free Edition.
As skills orientam o trabalho e não concedem autorização para implantar recursos.
